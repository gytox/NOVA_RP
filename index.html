ABOUT THE GAME

Hey! This is my first game ever. I've been learning game development and decided to just go for it. NOVA RP is an open-world roleplay game where you can explore, build, and interact with other players. It's a work in progress but the core gameplay is functional.

FEATURES

  • Open-world exploration
  • Multiplayer interaction
  • Custom character system
  • Building and crafting
  • Day/night cycle
Note from the dev: This is my very first project and I'm still learning. If you find bugs or have suggestions, I'd really appreciate your feedback! This game is free to download while I'm testing it.
